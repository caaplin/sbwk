# SBWK `v0.1.0` Technical Review — Confirmation & Applied Improvements

This document confirms the findings in `v0.1.0-technical_revi.md` against the repository source code (at commit `023df04`) and records the zero-dependency improvements implemented on this branch.

---

## 1. Architecture Walkthrough Confirmation

- **5 zero-dependency Node.js services (`middleware`, `agent-core`, `agent-connector`, `control-plane`, `dummy-server`)**: **Confirmed.** Every runtime container runs `FROM node:22-alpine` with `COPY *.mjs ./` and zero `npm install` steps.
- **Additional findings discovered during code audit (beyond the review):**
  1. **Bug in `services/agent-connector/adapters.mjs` timeout classification:** `inspectService` checked `err.code === "AbortError"`, whereas Node's `fetch`/`AbortController` sets `err.name === "AbortError"`. As a result, live connector timeouts fell through to `CONNECTION_FAILED` / `ABORT_ERR` instead of `"TIMEOUT"`. *(Fixed + tested.)*
  2. **Env var mismatch in `services/agent-connector`:** `.env.example` documented `EXTERNAL_API_TOKEN`, while `config.mjs` read `EXTERNAL_API_API_TOKEN`. *(Fixed: both `${PREFIX}_API_TOKEN` and `${PREFIX}_TOKEN` are now supported.)*
  3. **Node 22 test runner collision in `services/agent-connector`:** Leftover v1 TypeScript files (`test/connector.test.ts`) sit alongside `.mjs` tests; `package.json` ran bare `node --test`, which on Node 22+ attempts to execute `.ts` files with extensionless imports. *(Fixed: scoped to `node --test test/*.test.mjs`.)*
  4. **Missing `demo/` scripts:** Root `package.json` (`npm run demo`, `npm run stack`) and `services/control-plane/README.md` referenced `demo/run-demo.mjs` and `demo/run-stack.mjs`, which were missing from the repo. *(Added zero-dependency implementations.)*

## 2. Item-by-Item Confirmation of the 34 Limitations & Remediation Status

### Correctness / Functional

| # | Review Claim | Audit Verdict | Action Taken (Zero-Dependency) |
| --- | --- | --- | --- |
| **1** | `AUTO_ROLLBACK`, `DRY_RUN`, and `MONITORING_ACTIVE` are policy flags only; nothing executes or rolls back. | **Partially Confirmed (Nuance):** `DRY_RUN` and `AUTO_ROLLBACK` are indeed policy metadata only (by read-only design). However, `MONITORING_ACTIVE` **is functional** (`agent-core/server.mjs` short-circuits `POST /incidents` to `status: "received"` without running investigations when `false`). | Clarified UI labels and README so `autoRollback` is explicitly presented as policy metadata rather than active execution. |
| **2** | Codebase search is naive substring matching (`scoreContent` counts raw substring hits, matches comments equally). | **Confirmed.** | Upgraded `scoreContent` (`agent-core/codebase.mjs`) with word-boundary weighting (`\b...\b`), comment-line de-weighting (`0.25x`), handler/definition line boosting, filename relevance scoring, and minified-bundle skipping. |
| **3** | Non-HTTP dependencies (`mongodb+srv`, `postgres://`, `redis://`) only get DNS lookup and are skipped by `applyExternal`. | **Confirmed.** | Implemented real zero-dependency TCP/TLS socket handshakes (`node:net`, `node:tls`) + `dns.resolveSrv` for `mongodb+srv://` in both `control-plane/checks.mjs` and `agent-connector/adapters.mjs`, and updated `applyExternal` to push `tcpEndpoint` configs to the Connector. |
| **4** | Reasoning is heuristic by default (`AGENT_MODE=mock`) with static confidence numbers. | **Confirmed.** | Calibrated heuristic confidence dynamically using corroborating signal counts and codebase matches while preserving deterministic demo behavior. |
| **5** | Commit correlation is crude substring matching (e.g. `"update user docs"` matches `/users`). | **Confirmed.** | Upgraded `correlateCommit` (`agent-core/reason.mjs`) to use word-boundary matching, correlate matched handler filenames, and de-prioritize docs-only commits (`docs:`, `readme`, `typo`). |
| **6** | `deriveKeywords` uses a fixed 10-word vocabulary, missing `redis`, `s3`, `kafka`, `rate_limit`, etc. | **Confirmed.** | Expanded vocabulary to 45+ infrastructure/error terms, split camelCase/kebab-case route segments, and extracted function names from stack traces (`at fnName (...)`). |
| **7** | Connector contract validation is minimal (`{status:"healthy", checks:null}` or `metrics: []` passes). | **Confirmed.** | Strengthened `validateContract` (`agent-connector/adapters.mjs`) to reject arrays, validate `health.checks` map values, verify `metrics.metrics` entries are primitives/finite numbers, and verify `logs.logs` entries contain string `level` and `message`. |
| **8** | `mockCheck` mutates `structuredClone(health[service]).checks` and would throw on unknown service. | **Confirmed.** | Guarded `mockCheck` (`agent-connector/mock.mjs`) to return a structured `INVALID_ARGUMENTS` result on unknown services/checks. |

### Reliability / Operability

| # | Review Claim | Audit Verdict | Action Taken (Zero-Dependency) |
| --- | --- | --- | --- |
| **9** | Fire-and-forget dispatch never retries; 15s throttle can suppress subsequent failures even if dispatch failed or category differed. | **Confirmed.** | Added bounded exponential-backoff retry with jitter (`DISPATCH_MAX_RETRIES`, `DISPATCH_RETRY_BASE_MS`) in `middleware/server.mjs`, included `category` in `DispatchThrottle.key`, and released the throttle slot if all dispatch attempts fail. |
| **10** | Cooldown state (`DispatchThrottle.last`) is process-local `Map`. | **Confirmed.** | Kept zero-dependency in-memory design with bounded map cleanup; documented multi-replica behavior. |
| **11** | `IncidentStore.persist()` uses synchronous `writeFileSync` on every mutation without atomic write or locking. | **Confirmed.** | Replaced blocking `writeFileSync` in `agent-core/store.mjs` with a coalesced async write queue using atomic temp-file + `rename` (`mode: 0o600`), plus `flushSync()` on `SIGTERM`/`SIGINT` and optional `INCIDENT_TTL_MS`. |
| **12** | `MAX_CONTEXT_INCIDENTS` (200) silently forgets recurrence beyond 200 incidents. | **Confirmed.** | Added an extended lightweight recurrence ring (`max * 5`, min 1,000 entries) in `IncidentStore` so path recurrence survives beyond full-payload eviction. |
| **13** | Mutable runtime config lacks strict validation (`paths.logs` could be traversal or full URL overriding `baseUrl` in `new URL(path, baseUrl)`) and audit detail. | **Confirmed.** | Enforced `isSafeDiagnosticPath` + same-origin check in `agent-connector`, URL/range validation in `middleware` and `agent-core`, and structured audit logs (`requestId`, `actorIp`, `changed`). |
| **14** | No rate limiting anywhere across services. | **Confirmed.** | Added zero-dependency per-IP `RateLimiter` across `agent-core`, `agent-connector`, `control-plane`, and `middleware` admin routes (plus optional `PROXY_RATE_LIMIT_PER_MIN`). |
| **15** | Production token check only tests `startsWith("development-only")`, allowing weak or `.env.example` `replace-with-...` tokens. | **Confirmed.** | Added `isWeakToken()` across all services (`middleware`, `agent-core`, `agent-connector`, `control-plane`), rejecting `<32`-char, placeholder (`development-only`, `replace-with`, `replace-this`, `changeme`), and low-entropy tokens in production. |

### Security

| # | Review Claim | Audit Verdict | Action Taken (Zero-Dependency) |
| --- | --- | --- | --- |
| **16** | Up to 2 KB of upstream response body is stored and sent to Groq without PII/secret redaction. | **Confirmed.** | Added `redactSensitive` / `redactDiagnosticText` in both `middleware` and `agent-core` (redacting Bearer/Basic tokens, JWTs, API keys/PATs, URI credentials, secret JSON/query fields, and emails). |
| **17** | Untrusted incident fields (`userAgent`, `clientIp`, `responseSample`) go verbatim into LLM prompt; `suggestedFixes[].file` rendered in UI without URL sanitization. | **Confirmed.** | Omitted `clientIp` and `userAgent` from LLM prompts, isolated redacted evidence inside `<untrusted_evidence>` tags with anti-injection system instructions, clamped/validated LLM JSON schema, sanitized `suggestedFixes[].file` (`sanitizeFixFile` blocks `javascript:`, `data:`, `http:`, `..`), and hardened UI rendering. |
| **18** | Control plane stores GitHub token & API key in plaintext in `onboarding.json`. | **Confirmed.** | Implemented AES-256-GCM encryption at rest (`scryptSync` + random IV + auth tag, `enc:v1:...`) with `0o600` atomic file writes in `control-plane/store.mjs` and `PERSIST_SECRETS=false` support. |
| **19** | No CSRF protection on control-plane state-changing endpoints (`/api/gateway`, etc.). | **Confirmed.** | Added `verifyCsrf` (`control-plane/server.mjs`): enforces `Content-Type: application/json`, blocks `Sec-Fetch-Site: cross-site`, and validates `Origin` host match (or `ALLOWED_ORIGINS`). |
| **20** | `checkReachability` (and `/api/gateway`) is an SSRF primitive with no metadata/IP blocking. | **Confirmed.** | Added `isBlockedIp` + DNS-resolution pre-check (`validateTargetUrl`) blocking `169.254.0.0/16`, `100.100.100.200`, `0.0.0.0/8`, IPv4-mapped metadata, link-local/multicast, dangerous schemes, and open redirects (`redirect: "manual"`), plus configurable `BLOCK_PRIVATE_NETWORKS` + `SSRF_ALLOWLIST_HOSTS`. |
| **21** | `applyConfig` in Agent Core accepts arbitrary `codebase.commits` objects without schema validation. | **Confirmed.** | Added `sanitizeCommitEntry` (`agent-core/server.mjs`) validating hex SHAs, stripping control chars, and permitting only safe `https://` commit URLs. |
| **22** | `X-Forwarded-For` is trusted blindly (`fwd.split(",")[0]`). | **Confirmed.** | Added `TRUST_PROXY` (default `false`) and `sanitizeIp()` in `middleware/server.mjs` so spoofed or prompt-injection headers are ignored/sanitized. |
