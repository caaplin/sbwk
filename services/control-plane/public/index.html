// How it works

The pipeline

01

Intercept

A container takes inbound traffic and forwards it to your server, Cloudflare-style. Nothing reaches the app unread.

02

Detect

A built-in detector flags anomalies. 404s, 500s, slow responses — anything unusual gets dispatched to the core agent.

03

Diagnose

The agent pulls logs from your auth and database providers, then reads your codebase and compares it to recent commits.

04

Escalate

It proposes a fix. If confidence drops below your threshold, it stops and wakes the human engineer.

// Step 01 / 04

Network
Gateway

Sleepy Bot sits between the client and the server. It receives all traffic.

Point your DNS at the Sleepy Bot edge container. Your server stops receiving traffic directly — every request passes through the agent first.

Limits

The agent acts automatically. Set the limits before it does.
